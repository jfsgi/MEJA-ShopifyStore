# MEJA Designs — Shopify WebStore Program

> Planning & design package for the next-generation **mejadesigns.com** storefront, fed by the **MEJA‑CRM Quoting** platform, with **Atelier3d** custom design tooling and a **4K live‑rendering** engine.

This repository contains the **approval-stage deliverables** for the new store. Nothing here is production code yet — these documents define *what* we are building, *how* it fits together, *how it should look*, and *how each product type flows* from discovery to fulfillment. They are written to be reviewed, marked up, and approved before engineering begins.

## 🧭 How to review

1. **See the look first** — open [`mockups/index.html`](mockups/index.html) in a browser and skim the 10 iterations.
2. **Read the plan** — start with the Master Plan ([`docs/01-Master-Plan.md`](docs/01-Master-Plan.md)).
3. **Approve direction** — the "Open Decisions for Approval" section at the end of the Master Plan lists every choice that needs your sign-off (architecture, primary design iteration, scope of Phase 1, etc.).
4. **Mark up** — comment inline on the `.md` files, or edit the `.docx` versions in Word with track-changes.

## 🛠️ Regenerating the Word files

```bash
pip3 install python-docx markdown
python3 tools/build_docx.py
```

This reads the Markdown in `docs/` and writes styled `.docx` files into `word/`.

## 🔌 The four systems at a glance

| System | Role | Connection |
|--------|------|------------|
| **Shopify** | System of record for catalog, cart, checkout, orders, customers, payments. | Admin API + Storefront API + Webhooks |
| **MEJA‑CRM Quoting** | Builds quotes; pushes **private (unlisted)** and **hybrid** customized listings into the store. | REST + Webhooks via the Integration Layer |
| **Atelier3d** | 3D product configurator for **custom build-out** products. | Embedded SDK + Configuration API |
| **4K Render Engine** | Live high-resolution rendering of configured pieces. | Async render API (job → CDN asset) |

> Detailed contracts, sequence diagrams, and data flow live in the Master Plan (§API Integration) and Product Workflows documents.
